## What's here

<CardGrid>
  <Card title="Six real apps" icon="laptop">
    React, Vue, Svelte, Solid, Angular and Astro, each in its own idiom. They share logic and styles through
    one core package, so every difference comes from the framework.
  </Card>
  <Card title="Measured, not guessed" icon="random">
    Bundle sizes, line counts and build times from production builds, plus a query &amp; render benchmark run
    in the lab and in visitors' browsers.
  </Card>
  <Card title="Live data in Airtable" icon="seti:db">
    Countdowns, real-world benchmark runs and the latest build metrics are stored in Airtable, behind three
    small Vercel functions.
  </Card>
  <Card title="One test suite" icon="approve-check">
    A single Playwright spec runs against every demo with a frozen clock, so all six behave identically.
  </Card>
</CardGrid>
